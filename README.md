# StudyBuddy: AI Study and Learning Agent

StudyBuddy helps a student study from their own course materials: it ingests PDFs and notes, answers questions with citations, generates flashcards and quizzes, grades attempts and tracks weak concepts, all supported by a multi-step Study Coach agent.

## Repository layout

|-|-|
|`report/`|Stage 1 design report|
|`uml/`|UMLet diagrams (.uxf): class diagram, use-case diagram, sequence diagrams|
